# Required tests (COMPLIANCE.md §13) — where they are

Every rule in [`COMPLIANCE.md`](COMPLIANCE.md) §13 with the tests that check it today, or the build step
(CLAUDE.md §10) that brings the feature. Today: **4 covered, 7 partly, 12 not built yet**.

- **covered** — every part of the rule that exists is tested.
- **partly** — the parts that exist are tested; the rest arrives with the step named.
- **not built yet** — the feature doesn't exist; tests listed there are groundwork.

`pnpm test` runs [`scripts/check-compliance-tests.mjs`](scripts/check-compliance-tests.mjs): it fails when a
§13 rule has no row here (or its text changed) or when a test named here no longer exists. When you build a
feature, add its tests and move its row forward.
